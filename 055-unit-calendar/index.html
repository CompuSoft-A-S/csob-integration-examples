Dedicated Unit Calendar

This example embeds CSOB's standalone Unit Calendar component in wrapper mode. Unlike booking bar availability, the calendar itself owns the date bar, period buttons, and per-unit availability grid.

Usage notes

The Unit Calendar is rendered into #UnitCalendarWrapper and enabled with unitCalendarDisplayMode: 1.

Add ?cbpid=... or ?cbpids=... to the URL if you want to limit the example to one or more CompuBook profiles, similar to a custom accommodation selector on a host page.
