027 – Deep Linking

Pre-set dates and filters via URL query parameters. Left panel builds the query, right panel shows the booking site.

Active: None — using defaults

Build & apply deep link

Note: profileIds and profileItemId filter results but are not reflected in the filter checkboxes. Only ?filter= affects the visible filter panel.
Example links (dynamic dates):
Param Option Description
from from Start date (dd-mm-yyyy)
to to End date (dd-mm-yyyy)
pids profileIds Multiple profile IDs
pid profileId Single profile ID
piid profileItemId Shop item deep-link
siteid siteId Limit to site
lang language UI language
