How it works

The booking bar builds a URL with ?from=DD-MM-YYYY&to=DD-MM-YYYY and navigates here. The CSOB controller reads the query parameters and displays results for the selected period.

In production, the booking bar would typically live on the homepage, and searchUrl points to a dedicated booking page.
